## 🎓 Архитектурные принципы реализованы

### 1. ✅ Separation of Concerns
- **Persistence Layer** (JPA) → Только DB операции
- **Planning Layer** (POJOs) → Только solving
- **API Layer** (DTOs) → Только контракты
- **Mapping Layer** (Mapper) → Конвертация между слоями

### 2. ✅ Single Responsibility Principle
Каждый класс имеет одну ответственность:
- `Lesson` → Persistence
- `PlanningLesson` → Solving
- `PlanningModelMapper` → Conversion

### 3. ✅ Dependency Inversion
`SolverService` зависит от абстракций (mapper interface), а не от конкретных JPA entities

### 4. ✅ Clean Architecture
```
┌────────────────┐
│   Controllers  │ ← Presentation Layer
├────────────────┤
│   Services     │ ← Business Logic
├────────────────┤
│ Mappers/Domain │ ← Domain Layer
├────────────────┤
│  Repositories  │ ← Data Access Layer
└────────────────┘
```
